Exif Exorcist v1.0

An offline, single-file tool that strips metadata in your browser. No install, no server, nothing leaves the page.

Authorized use only

Use this on files you are allowed to modify. It rewrites bytes you give it. It does not upload them, and it does not redact what a person can see in the picture or on the page. A result of “No metadata detected” is what the re-scan measured for a fully supported format. Best-effort formats are never given that result. Check anything you depend on with another tool, such as exiftool.

How to strip

Canvas re-encode throws the original file away and builds a new PNG from pixels. Metadata does not carry over, but quality can drop, color can shift, bit depth is flattened, and animations keep only the first frame. Use it when you accept that loss, or when a best-effort container still shows metadata.
