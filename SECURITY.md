# Security Policy

## Supported versions

Security fixes are provided for the current release.

| Version | Supported |
| --- | --- |
| 1.0 | Yes |

## Reporting a vulnerability

Report security vulnerabilities privately through GitHub Security Advisories:

[Open a security advisory](https://github.com/connor-sec/Exif_Exorcist/security/advisories/new)

Describe the issue, the version you tested (the release tag, or the `Exif-Exorcist-v*.html` file you built), and how to reproduce it. Do not open a public issue, pull request, or discussion for a report that should stay private.

## Authorized use

Exif Exorcist rewrites files you choose and keeps that work in the browser. Use it only on files you are allowed to modify. Stripping metadata from a file you do not have rights to, or removing metadata you are required to keep, may violate law, contract, or policy. A scan result is not a certification that a file is clean.
